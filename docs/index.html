Reportar un problema
¿Qué es exactamente winmail.dat?

Es un archivo contenedor en formato TNEF que Outlook puede utilizar para enviar adjuntos y formato enriquecido. No implica por sí mismo que el mensaje esté cifrado.

¿LookOut-Mily puede leer correos cifrados sin firma?

Un mensaje S/MIME u OpenPGP cifrado necesita la clave legítima del destinatario aunque no tenga firma. El complemento evita modificar esos mensajes protegidos; no elude su cifrado.

¿Se borra mi correo original al convertirlo?

No con la versión 3.6: si decides generar una copia MIME, el correo original se mantiene. La creación de copias está desactivada inicialmente.

¿LookOut-Mily 3.6.0 ya está publicada?

Sí. La 3.6.0 es la versión pública del proyecto en GitHub. El mantenedor confirmó su instalación y las pruebas automatizadas pasaron. La revisión en el catálogo ATN es opcional; todavía se están ampliando las pruebas con mensajes Outlook reales.

¿Funciona en versiones antiguas de Thunderbird?

Se declara compatible con Thunderbird 128 y versiones posteriores, con verificaciones simuladas de APIs en 128, 140, 153 y 158. Thunderbird 115 no está incluido en el soporte previsto para 3.6.

¿Cómo recibiré avisos cuando haya otra versión?

La 3.6 consulta versiones en GitHub y notifica cambios compatibles. El paquete público también incluye una URL nativa de actualización de Thunderbird. Las actualizaciones automáticas dependen de las preferencias del usuario y requieren una versión superior a la instalada.
